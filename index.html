Cross-Department

Inter-Department Workflow & Rules

We run on a system, not on favours.

✕ Before — No System

  • Direct WhatsApp tags to designers/copywriters
  • Private msgs: "really urgent please help"
  • 5-day lead time ignored, always last minute
  • Poster in group "pls check" = expected QC
  • No data ownership → mistakes blamed on marketing
  • No tracking, tasks fall through cracks

✓ After — Systematic

  • All requests via ClickUp Creative Request Form
  • Auto-tracked task with brief + deadline
  • 5 working days enforced — emergency needs Manager OK
  • Data accuracy = requester's responsibility
  • Max 2 revision rounds per request
  • Full audit trail: request → assign → deliver

Additional Proposal — Extended Department Scope

The department manages the ad pipeline that generates all recruitment leads. With the current handler departing, this proposal extends scope to restructure the function — ensuring ad spend converts to actual hires.

Additional Proposal

Recruitment Pipeline Restructuring

From "run ads and hope" to a system with tracking at every stage.

Current Problems

No documented flow — one person, no tracking, no visibility. She is now leaving.
No conversion data — 400+ leads, zero data on CPL, response rate, or which campaigns work.
No nurturing — "not now" leads are lost. Every lead is one-shot.
Replacing a person ≠ fixing the structure — a system and broader scope are needed.

Proposed Funnel

Meta Lead Ads + Engagement Ads
Run by Marketing Dept — ads, targeting, creative
▼
Leads Captured in CRM / Tracking System
Auto-logged: source, date, campaign, status
▼
Recruitment Exec Contacts Within 24 Hours
Call/WhatsApp — qualify: Interested / Not Ready / No Response
▼
Interested → Schedule Interview with Leader
CMO assigns to appropriate team leader
▼
Accept → Onboard → Track Full Conversion
Measure: cost-per-hire, conversion rate, time-to-join

Not Ready → Nurture Pipeline

Monthly touchpoint. Share culture & success content. Re-enter funnel when ready.

No Response → 3-Attempt Protocol

3 attempts over 2 weeks → archive. Quarterly mass re-engagement campaign.
