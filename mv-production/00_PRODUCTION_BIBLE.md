# PropNex 主題曲動畫 MV｜製作聖經 (Production Bible)

> **歌曲**：《Sharpen the Wing》(PropNex Malaysia 主題曲)
> **形式**：CG 3D 動畫音樂錄影帶 (Animated Music Video)
> **片長**：2 分 33 秒 (153 秒 / ~143 BPM / 雙副歌)
> **風格**：**《Inside Out》鮮明角色 + 《Soul》靈魂溫度** 的寫實卡通（Pixar/Universal 級 CG）
> **結構**：8 個環節，各自獨立支線、串連成一齣完整的劇
> **核心**：兩位男 leader（阿凱・精進的火 × 阿俊・溫暖的光）從菜鳥到大團隊領袖的雙主線
> **用途**：對外品牌片；用於培訓 / 大培訓 / 年會 / 頒獎
> **公司背景**：PropNex Malaysia，2018 年由四位老闆引進品牌（恰好 8 年）；
>   願景 To Be Market Leader（透過培訓與人才發展）；信條 Good to Great · Think Big · Thousands to Millions · 4E。

## 1. 一句話故事 (Logline)

> 八年前，當所有人都說「不可能」的時候，兩個一無所有的年輕人，
> 選擇相信四位創辦人手中那束微光——
> 八年後，他們帶著當年留下來的人，把 67 個人的小團隊，
> 變成遍佈全馬、2000 人的家。
> 這不是一間公司的故事，這是一群人決定「相信」的故事。

---

## 2. 主題與精神內核 (Theme & Premise)

**外在故事 (Plot)**：一間公司 8 年從 67 人 → 2000 人、遍佈全馬的成長史。

**內在故事 (Theme)**：**「相信」會複製。**
- 一個人相信一束光 → 一群人圍著這束光 → 這束光被傳給下一代 → 最後照亮千千萬萬個家庭。
- 願景具象化：**To be Market Leader** = 不是打敗誰，而是「改變市場生態圈」，
  打造一個**讓年輕人安心創業的平台**，實現**「事業成功，家庭幸福」**。

**情感弧線 (Emotional Arc)**：
`懵懂的相信 → 被質疑的孤獨 → 咬牙的堅持 → 第一次被看見 → 開始傳承 → 燎原 → 回望與感恩 → 把光交給未來`

**全片母題符號 (Motif)**：**一束光 / 一盞燈**。
- 起點：創辦人手中一顆微弱的光點（品牌的火種）。
- 過程：光被分給每個願意相信的人，每人手中一盞燈。
- 結尾：2000 盞燈連成一片星海，覆蓋馬來西亞地圖，最後升空成為一顆「市場上的北極星」。

## 3. 雙主角設定（故事核心）

> 兩位男性 leader，皆為虛構代言角色（佔位名，可替換）。風格：Inside Out 鮮明 + Soul 靈魂溫度。

### 阿凱 (Kai) — 「精進的火」（藍火 `#0070E0`）
- 人設：專注帶團隊、瘋狂自我精進、緊跟四位老闆做大量培訓。
- 主導情緒：決心 (Determination)。胸口一束會隨成長變亮的藍色學習之火。
- 弧線：菜鳥黃毛 → 蛻變 → 成為「建系統」的大團隊 leader。

### 阿俊 (Jun) — 「溫暖的光」（暖琥珀 `#E9A23B`）
- 人設：好大哥、暖男，主動幫助身邊需要的 agent、接住每一個人。
- 主導情緒：共情 (Empathy/Warmth)。胸口一團能安定他人的琥珀暖暈。
- 弧線：靦腆新人 → 小組依靠 → 成為「凝聚團隊＝家」的大團隊 leader。

**雙主線設計**：阿凱（藍/理性/精進/向上）× 阿俊（琥珀/感性/關懷/凝聚）＝
PropNex「培訓系統 × 團隊文化」的兩條腿。第④副歌交會、第⑥橋段阿俊主場、第⑦兩色交織成燈海。

### 四位老闆（真名・全片穿插引路人）
**Marcus Teng（CEO）/ Evon Heng（Executive Director）/ Steve Tong / Yuki Wan**——
不只開場，而是在每個關鍵節點「恰好在場」（培訓台、頒獎、project 現場、合影）。
真人公開人物，需風格化寫實肖像 + 簽核授權。詳見 `02_CHARACTER_DESIGN.md`。

## 4. 配角與世界觀

| 角色 | 定位 | 視覺記憶點 |
|------|------|-----------|
| 四位創辦人 (The Four) | 引路人 / 精神導師，手持「火種之光」 | 四人剪影 + 一盞共同點亮的燈；不搶主角戲份，多以光與背影呈現 |
| 67 位初始夥伴 | 「願意相信而留下來的人」 | 群像，每人胸口一點微光 |
| 質疑者群眾 (The Doubters) | 阻力象徵（家人、旁人、市場） | 灰冷色調、背對主角、撐傘的人潮 |
| 下一代 leader | 被複製、被點亮的新血 | 年輕、明亮，接過燈的手 |
| 2000 人大家庭 | 第 7 段的群眾高潮 | 覆蓋全馬地圖的燈海 |

**世界觀視覺隱喻**：整部片用「天氣與光」對應「信念與時局」。
- 不被看好 = 下雨、灰霧、逆風。
- 堅持 = 雨中仍亮著的那盞燈。
- 突破 = 雲開、第一道陽光。
- 燎原 = 日出、燈海、暖金。

## 6. 視覺與藝術指導（摘要）

- **風格定位**：Pixar 溫暖寫實卡通——圓潤可親的角色 + 物理正確的次表面散射 (SSS) 膚質 + 電影級景深與體積光 (volumetric light)。
- **角色比例**：頭身比約 1:5（比寫實略 Q，但保留真實情感肌肉與眼神）。
- **鏡頭語言**：以淺景深、手持微晃的「擬真攝影機」營造紀錄片式真實感；情緒高點用環繞長鏡頭 (oner)。
- **色彩劇本主軸**：冷→暖的全片漸變。第 1–3 段壓低彩度（青灰、雨藍），第 4 段開始回暖，第 6–8 段全暖金、蜜橘、晨光。
- 完整美術設定與 color script 見 `03_ART_DIRECTION_COLORSCRIPT.md`。

## 7. 音樂對位原則

- 既有主題曲 (2:33) 為**剪輯主骨**——先鎖歌曲結構（前奏 / 主歌 A / 副歌 / 橋段 / 大副歌 / 尾奏），再對位 8 環節。
- 副歌＝情緒最高點＝視覺「光」最強的環節（第 6、7 段）。
- 歌詞關鍵字（願景、相信、家庭、市場領導者）需與畫面母題卡點同步 (lip-to-beat & lyric-to-visual sync)。
- 完整逐句對位見 `05_MUSIC_SYNC_MAP.md`。

## 8. 製作流程總綱（Pixar / Universal CG Pipeline）

分四大階段、共 13 個工序。完整版見 `04_CG_PIPELINE.md`。

```
開發 Development
 └─ 1. 故事 / 劇本 / Treatment

前期 Pre-Production
 ├─ 2. 角色設計 & Model Sheet
 ├─ 3. 視覺開發 Visual Development + Color Script
 ├─ 4. 分鏡 Storyboard
 └─ 5. 動態分鏡 Animatic（鎖音樂、鎖時長）

製作 Production
 ├─ 6. Layout（攝影機 & 場景走位）
 ├─ 7. 建模 Modeling + 8. 綁定 Rigging
 ├─ 9. 材質 Surfacing / Shading / Texturing
 ├─ 10. 動畫 Animation（+ 群眾 Crowd Sim）
 ├─ 11. 特效 FX（雨、光、燈海、體積霧）
 └─ 12. 燈光 & 算圖 Lighting & Rendering

後期 Post-Production
 └─ 13. 合成 Compositing → 調色 → 音樂混音 → 成片 Master
```

## 9. 製作路線建議（依預算）

| 路線 | 工具 | 製期 | 適合 |
|------|------|------|------|
| A. 全 CG 工作室級 | Maya/Houdini/RenderMan | 4–6 個月 | 高預算、要長期文化資產 |
| B. 中階獨立製作 | Blender + EEVEE/Cycles | 2–3 個月 | 中預算、品質與成本平衡（**推薦**） |
| C. AI 輔助快速版 | AI 生成 + Blender 修整 | 4–8 週 | 趕活動檔期、預算有限（見文件 07） |

> **本聖經採「路線 B 為主、路線 C 為備案」雙軌設計**，
> 所有美術與分鏡規格皆可向上相容到路線 A。
