# 02｜角色設計 & Model Sheet 規格

> Pixar 溫暖寫實卡通：頭身比 ~1:5，圓潤親和但保留真實情感肌肉、眼神、次表面散射膚質。
> 每個角色需產出：**三視圖 (front/side/3-4)**、**表情表 (expression sheet)**、**色彩設定 (color callout)**、
> **比例對照 (size comparison)**、**服裝/道具 (props)**。

---

## 1. 阿浩 (Hao) — 「行動派的傻勁」｜主角 A

| 項目 | 設定 |
|------|------|
| 角色定位 | 系統建立者；衝、敢、講義氣 |
| 體型 | 中等偏精實，動作大、重心前傾（永遠像要往前衝） |
| 臉部 | 濃眉、大眼、嘴角天生上揚；情緒外放 |
| 標誌動作 | 握拳、捲袖子、拍肩膀 |
| 色彩 | 主色暖橙 (#E8743B)，象徵行動力 |
| 道具 | 一盞「行動之燈」——燈罩偏方正、光偏暖白 |

### 成長三階段（同一角色、造型漸變）

| 階段 | 出現環節 | 造型關鍵 |
|------|----------|----------|
| 黃毛小子 | ②③ | 廉價 T-shirt、瀏海亂、眼神帶不服輸 |
| 成形期 | ④⑤ | 襯衫捲袖、站姿變穩、眼神聚焦 |
| 大團隊 leader | ⑥⑦⑧ | 合身西裝/品牌服、肩線打開、眼神溫定有威 |

## 2. 凱琳 (Karlin) — 「相信的力量」｜主角 B

| 項目 | 設定 |
|------|------|
| 角色定位 | 文化守護者；穩、細膩、凝聚人心 |
| 體型 | 修長、姿態端正，動作收斂優雅 |
| 臉部 | 杏眼、眼神溫柔但堅定；笑起來有安撫力 |
| 標誌動作 | 把手放在別人肩上、傾聽時微微前傾 |
| 色彩 | 主色暖金 (#E9B949) + 一抹品牌色，象徵溫度與信念 |
| 道具 | 一盞「信念之燈」——燈罩偏圓潤、光偏蜜金 |

### 成長三階段

| 階段 | 出現環節 | 造型關鍵 |
|------|----------|----------|
| 黃毛小子 | ②③ | 樸素、馬尾、會咬唇猶豫 |
| 成形期 | ④⑤ | 俐落短髮/盤髮、眼神篤定 |
| 大團隊 leader | ⑥⑦⑧ | 大方得體、氣場溫暖、成為眾人依靠 |

> **兩盞燈的設計是關鍵**：阿浩（方正暖白）+ 凱琳（圓潤蜜金），在第④段「合而為一」時，
> 兩種燈罩造型與光色融合成一盞「方圓並濟、暖金白」的大燈——這是全片最重要的視覺隱喻。

## 3. 四位創辦人 (The Four) — 引路人

- **不給清晰五官**，以剪影 + 逆光 + 手部特寫呈現，保持「精神導師」的崇高與神秘。
- 四人各持火種的一角，第①段「四隻手共護一光」是他們的代表畫面。
- 若公司希望露臉，可在第⑧段尾奏給一個四人並肩的暖光背影（不搶主角）。
- 設計理由：本片要 **highlight 兩位 leader 是主角**，創辦人作為光的「源頭」而非戲份主體。

## 4. 配角群

| 角色 | 設計重點 |
|------|----------|
| 67 位初始夥伴 | 8–10 種「基礎角色原型」(base mesh) 換色換裝複製出 67 人；每人胸口一點微光 |
| 質疑者群眾 | 灰階、低彩度、面部模糊化（不需精細），多為背影與黑傘剪影 |
| 下一代 leader | 年輕、明亮、眼神有光；第⑥段接燈的主要對象 3–5 位需精細設計 |
| 2000 人燈海 | 以 crowd sim 的 instance agent 處理，遠景不需個別五官 |

## 5. 角色 Model Sheet 產出清單（製作方交付物）

每個「需精細」角色（阿浩、凱琳、3–5 位新生代）必須交付：
1. **Turnaround** 三/四視圖（T-pose）
2. **Expression sheet**：至少 8 種表情（喜/猶豫/失落/堅定/感動/笑/淚/凝視）
3. **Color script callout**：三個成長階段各一組配色
4. **Rig 規格**：臉部 blendshape 清單（FACS-based，至少 30 組）+ 身體 IK/FK
5. **道具**：個人燈具的 model + 發光材質參數

## 6. 風格錨點 (Style Anchors) — 給美術/外包的參考片

- 角色親和度與情感 → 《Soul》《Inside Out》
- 溫暖寫實膚質與光 → 《Luca》《Coco》
- 群眾燈海與規模感 → 《Coco》亡靈節燈海、《Tangled》天燈場景
- 光之鳥/光粒子母題 → 《Soul》靈魂世界的光形態

> ⚠️ 上述僅為**內部風格溝通參考**，最終成片不得直接複製任何受版權保護的角色或畫面。
