# 03｜美術指導 & 色彩劇本 (Art Direction & Color Script)

> 色彩劇本是 Pixar 流程的靈魂——用「顏色」說情緒。本片主軸：**冷 → 暖** 的全片漸變，
> 對應「懵懂質疑 → 信念燎原」。下方為 8 環節的逐段色彩與光影設定。

---

## 1. 全片色彩弧線 (Color Arc)

```
彩度/色溫
暖金 ████                                    ████████  ← ⑦⑧ 燈海/北極星(最暖)
       │                  ███ ████ ████
中性   │        ██  ████                          
       │   ██                                      
冷藍 ██│██                                         
       └──①──②──③──④──⑤──⑥──⑦──⑧──→
        火種 留下 雨  副歌 建立 傳承 全馬 願景
```

- **①–③**：低彩度、冷色（青灰 / 雨藍 / 鋼藍）。世界是灰的，唯一的暖色是「手中的燈」。
- **④**：第一次回暖——雲開、第一道金色陽光刺入冷色世界（強烈對比＝情緒爆點）。
- **⑤**：中性暖（木質、米、燈塔黃），踏實建設感。
- **⑥**：暖色開始蔓延（蜜金點點）。
- **⑦–⑧**：全暖——金、橘、蜜、晨光。最高彩度與最暖色溫。

## 3. 鏡頭與攝影語言 (Cinematography)

- **鏡頭情緒**：擬真實體攝影機——淺景深 (shallow DoF)、輕微手持晃動 (subtle handheld)，營造紀錄片真實感。
- **焦段策略**：情感戲用長焦 (85mm 等效) 壓縮、貼近角色；規模戲 (⑦) 用廣角 (18–24mm) + 空拍。
- **運鏡標誌**：
  - 情緒高點 (④⑦) 用**環繞長鏡頭 (oner)** 一鏡到底，增強沉浸。
  - 低谷 (③) 用**固定機位 + 冷靜剪接**，製造壓抑。
  - 傳承 (⑥) 用**慢動作 (slow-mo)** + 淺景深，放大儀式感。
- **構圖母題**：「光」永遠是畫面的視覺重心 (focal point)；質疑者永遠背光/失焦。

## 4. 光影聖經 (Lighting Bible)

| 情緒 | 光的行為 |
|------|----------|
| 希望初現 (①②) | 單點暖光在冷暗中「呼吸」，bloom 柔散 |
| 孤獨 (③) | 冷光為主，暖光僅剩「一盞不滅的燈」，雨中反光 |
| 突破 (④) | 體積光/神光 (god rays) 強勢刺入，冷暖強對比 |
| 建設 (⑤) | 暖燈漫射、均勻、安定，燈塔光束有方向性 |
| 燎原 (⑥⑦) | 點光源數量爆炸性增加，全局 GI 暖反彈 |
| 昇華 (⑧) | 高 key、暖暈、過曝邊緣 (highlight bloom)，如晨光 |

**核心規則**：全片只有一種「主動光源」——**信念之燈**。所有環境光都是它的延伸與反射。
燈越多＝信念傳得越廣＝畫面越暖越亮。這是把「抽象願景」變成「可見光量」的設計。

## 5. 字體 / 字卡 / 品牌規範

- 結尾字卡與數字「67 → 2000」以**光粒子書寫動畫**呈現（不要硬切字）。
- 字體：建議品牌標準字 + 一套襯線/無襯線中英對照（中文用思源黑體/品牌字，英文用 Geometric Sans）。
- 品牌色須在第④段之後「自然融入」暖色盤，不要生硬貼 Logo——讓品牌＝那束光。
- Logo 只在最後 8-3 定格出現一次，避免廣告感、保留電影感。

---

## 6. 交付物 (Color Script Deliverables)

1. 8 張**色彩劇本關鍵幀** (color key)，每段一張代表性畫面。
2. 1 張**全片色彩條** (color strip)，153 秒橫向縮覽，檢查冷暖節奏。
3. **Lighting reference 包**：每段的主光/補光/輪廓光配置圖。
4. **LUT / 調色基調**：建議成片套一致的暖調 film LUT，保留陰影冷、高光暖的「日落感」。
