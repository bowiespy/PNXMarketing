# 03｜美術指導 & 色彩劇本 (Art Direction & Color Script) — PropNex

> 色彩劇本＝用顏色說情緒。本片建立在 **PropNex 品牌色** 之上，疊加「雙主角光系統」。
> 全片色彩弧線：**灰冷質疑 → 藍色精進 → 藍金交融 → 暖金家園**。

> 最終兩色交融成「**藍金燈海**」——正是「事業成功 × 家庭幸福」的視覺合一。

## 1. 全片色彩弧線 (Color Arc)

```
彩度/暖度
暖金 ████                                        ████████ ← ⑥⑦⑧ 暖金/藍金(最暖最亮)
       │                  藍金 ███ ████ ████
品牌藍 │        ██  ████(藍火漸亮)                     
       │   ██                                          
質疑灰 ██│██                                            
       └──①──②──③──④──⑤──⑥──⑦──⑧──→
        火種 打拼 質疑 蛻變 建立 家   全馬 願景
```

- **①** 黑底 + 藍金火種（品牌藍 × 暖金的火）。
- **②③** 低彩度、質疑灰為主；唯一暖色是阿俊的琥珀光、唯一亮色是阿凱的藍火。
- **④** 副歌：灰被藍光擊穿，藍火與暖光第一次交融成藍金（情緒爆點）。
- **⑤** 建立：品牌藍主場（培訓塔、系統），暖琥珀點綴（團隊大樹）。
- **⑥** 橋段：全片最暖——家窗暖光、阿俊琥珀光主導。
- **⑦** 大副歌：藍金燈海、最高彩度。
- **⑧** 願景：暖白金北極星 + 家窗暖橘，最高明度。

## 3. 攝影語言 (Cinematography)

- **基調**：擬真實體攝影機——淺景深、輕微手持晃動，紀錄片真實感（呼應歌詞 "No fancy filters / Real life results"）。
- **焦段**：情感戲長焦 (85mm 等效) 貼角色；規模戲 (⑦) 廣角 (18–24mm) + 空拍。
- **運鏡標誌**：高點 (④⑦) 環繞長鏡頭 oner；低谷 (③) 固定機位冷靜剪；家/傳承 (⑥) 慢動作 + 淺景深。
- **構圖母題**：藍火/暖光永遠是視覺重心；質疑者永遠背光/失焦/低彩度。
- **「Think Big」運鏡規則**：每唱到 Think Big，鏡頭做一次「快速拉開景別 (snap zoom-out / dolly-out)」，把小格局瞬間放大成大格局——用運鏡演歌詞。

## 4. 光影聖經 (Lighting Bible)

| 情緒 | 光的行為 |
|------|----------|
| 希望初現 (①) | 藍金火種在黑暗中呼吸，bloom 柔散 |
| 真實打拼 (②) | 冷月光 + 一桌暖燈；阿凱藍火/阿俊暖暈是僅有的彩光 |
| 孤獨 (③) | 冷光為主，暖光僅剩阿俊傘下一團，雨中反光 |
| 突破 (④) | 體積神光 (god rays) 刺入，藍光擊穿灰，藍金交融 |
| 建設 (⑤) | 品牌藍均勻漫射 + 塔光束方向性，安定踏實 |
| 家・柔軟 (⑥) | 暖琥珀主導，家窗暖橘，高 key 柔光 |
| 燎原 (⑦) | 點光源爆量、GI 藍金反彈、燈海 |
| 昇華 (⑧) | 高 key 暖白金、過曝邊緣 bloom，如晨光/星光 |

**核心規則**：全片只有兩種「主動光源」——阿凱的**藍火（精進）** 與阿俊的**暖光（關懷）**。
環境光都是它們的延伸。光越多越交融＝事業與家庭越圓滿＝畫面越藍金越亮。

## 5. 字體 / 字卡 / 品牌規範

- 字卡與「67→2000 / thousands to millions」以**藍金光粒子書寫動畫**呈現，不硬切。
- 字體：PropNex 品牌字 + 中英對照（中文思源黑/品牌字，英文 DM Sans，呼應公司網站用字）。
- 品牌藍須自第④段起自然成為主色；Logo 僅在 8-3 定格出現一次，保留電影感、避免廣告感。
- 字幕慣例：沿用公司 **CN+EN 雙字幕** 標準（呼應 YouTube series 做法）。
