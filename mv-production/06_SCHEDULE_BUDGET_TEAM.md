## 2. 團隊編制 (Crew)

### 路線 B 最小可行團隊（6–9 人）

| 角色 | 人數 | 職責 |
|------|------|------|
| 導演 / 製片 | 1 | 故事、節奏、簽核、對接公司 |
| 美術 / 概念設計 | 1 | 角色設計、color script、分鏡 |
| 3D Generalist（建模/材質） | 2 | 角色、場景、道具、貼圖 |
| 角色動畫師 | 2 | 表演動畫（最關鍵人力） |
| FX / 燈光 / 算圖 (TD) | 1–2 | 雨、燈海、體積光、render |
| 合成 / 剪輯 / 調色 | 1 | 後期成片 |
| 音效 / 混音 | 1（可外包） | 環境音、混音 |

> 一人可身兼數職（generalist），小團隊用 Blender 全流程最省溝通成本。

## 3. 預算分級 (Budget Tiers, MYR)

| 項目 | A 工作室級 | B 獨立製作 | C AI 輔助 |
|------|-----------|-----------|-----------|
| 前期（故事/設計/分鏡） | 30k–60k | 12k–25k | 5k–12k |
| 建模/綁定/材質 | 60k–120k | 20k–40k | 8k–18k |
| 動畫 | 80k–160k | 30k–55k | 10k–22k |
| FX/燈光/算圖 | 50k–100k | 18k–35k | 6k–15k |
| 後期（合成/調色/混音） | 25k–45k | 10k–20k | 5k–12k |
| 算圖農場/算力 | 15k–40k | 5k–12k | 2k–6k(含AI訂閱) |
| **總計概算** | **260k–525k** | **95k–187k** | **36k–85k** |

> 數字為區間概算，受角色數、群眾規模(⑦燈海)、4K 與否、改稿輪次影響甚大。
> **省錢關鍵**：①鎖死 animatic 不返工 ②群眾用 instancing 不逐個做 ③重複資產 (base mesh) 複用。

## 4. 里程碑與簽核點 (Milestones & Gates)

| 里程碑 | 對應 Gate | 簽核人 |
|--------|-----------|--------|
| M1 故事+劇本定稿 | Gate A | 四位創辦人 + 兩位主角 leader |
| M2 角色+色彩定稿 | Gate B/C | 導演 + 公司品牌窗口 |
| M3 Animatic 鎖定（**最重要**） | Gate E | 全體決策層 |
| M4 動畫 50% review | Gate J（中期） | 導演 |
| M5 全片燈光算圖完成 | Gate L | 導演 |
| M6 終審成片 | Gate M | 四位創辦人 + 兩位主角 leader |

> **改稿政策**：M3 之後改「時長/結構」走變更單 (change order)，避免無限返工拖垮預算。

---

## 5. 風險與對策 (Risks)

| 風險 | 對策 |
|------|------|
| 群眾燈海 (⑦) 算力爆量 | 用 instancing + 體積/粒子替代逐個建模；遠景降模 |
| 動畫工時超支（最常見） | 主角戲精做、配角群用循環動畫 (cycle)/群眾 sim |
| 改稿失控 | M3 鎖 animatic，後續走變更流程 |
| 檔期太趕 | 切到 C 路線（AI 輔助，見 `07`），或先做 90s 精華版 |
| 真人 leader 形象還原度 | 提供多角度照片，model sheet 階段先比對簽核 |
