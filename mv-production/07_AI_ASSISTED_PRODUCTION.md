# 07｜AI 輔助快速製作路徑 (路線 C)

> 當檔期極趕或預算有限時的備案：用 AI 生成 + 人工修整，4–8 週產出一支「視覺接近 Pixar 溫暖卡通」的 MV。
> ⚠️ 取捨誠實說明：AI 路線在**角色一致性、精準對嘴、複雜表演、品牌形象還原**上不如純 CG，
> 適合「氛圍敘事型 MV」，不適合需要精確角色連戲的長劇情。本片的「光/燈/燈海」母題其實**很適合 AI**。

---

## 1. 路線 C 的核心策略

把 8 環節分成兩類處理：

| 類型 | 環節 | 作法 |
|------|------|------|
| **氛圍/意象段**（AI 強項） | ①火種 ③雨 ⑥傳承光 ⑦燈海 ⑧北極星 | 直接用 AI 影像生成 + 後期合成 |
| **角色表演段**（需一致性） | ②登場 ④副歌 ⑤建立 | AI 生成 keyframe + 人工 3D/2D 補動畫，或用角色一致性工具鎖臉 |

> 母題設計（光、燈、星海、天氣）刻意做成「意象主導」，正是為了讓 AI 路線可行——
> 大量畫面是「光的行為」而非「角色細節對嘴」，AI 生成成功率高。

---

## 2. AI 工具鏈 (Toolchain)

| 工序 | 工具選項 | 用途 |
|------|----------|------|
| 概念/分鏡稿 | Midjourney / DALL·E / Firefly | 快速出 color key、分鏡關鍵幀 |
| 角色一致性 | 角色參考 (character reference / cref)、LoRA 微調 | 鎖定阿浩/凱琳的臉與造型跨鏡頭一致 |
| 影像生成→動態 | Runway / Kling / Veo / Pika / Luma | 把關鍵幀生成 4–10s 動態鏡頭 |
| 首尾幀控制 | 上述工具的 start/end frame 功能 | 控制鏡頭運動與轉場接點 |
| 3D 補強（可選） | Blender + AI 貼圖 | 需精準運鏡/連戲的鏡頭用真 3D |
| 對嘴（如需要） | 對嘴/lip-sync 工具 | 副歌主角開口唱 hook |
| 升頻/補幀 | Topaz Video AI | 拉到 4K、補到 60fps 再降 |
| 合成/調色/剪輯 | After Effects + DaVinci Resolve | 統一色調、卡音樂、加字卡光粒子 |

> 工具迭代極快，以上為**類別建議**；採用前確認各工具的**商用授權**與**版權條款**。

## 3. 路線 C 工作流（4–8 週）

```
週1   故事/分鏡(沿用本repo 00-03) + animatic(鎖音樂)        ← 與純CG共用,不能省
週2   角色一致性建立(cref/LoRA) + color key 全段定稿
週3-5 逐鏡 AI 生成(每鏡多版選優) + 角色段人工補強
週6   合成/轉場/字卡光粒子 + 燈海堆疊
週7   調色(暖調LUT) + 音效/混音 + 對音樂卡點
週8   試播/修正/輸出多版本
```

> **animatic 仍不可省**——AI 路線最容易翻車的就是「生成一堆漂亮鏡頭但接不起來」。
> 先有鎖定的 animatic，AI 才是「填空」而非「亂槍打鳥」。

## 4. 一致性與品質保命技巧

1. **角色聖經先行**：用 model sheet (`02`) 餵 AI 做 character reference，每個鏡頭都帶同一參考。
2. **色彩劇本當錨**：每段把 `03` 的 HEX 色盤寫進提示詞，確保冷暖弧線不亂。
3. **母題優先**：多用「光、燈、剪影、逆光、天氣」這些 AI 擅長且本片需要的元素。
4. **角色臉少給大特寫**：AI 大特寫易崩臉與抖動；本片角色情緒多用中景 + 光影，反而更穩。
5. **2000 人燈海交給 AI**：群眾與燈海是 AI 強項，純 CG 反而貴——這段用 AI 最划算。
6. **真人 leader 還原**：若要還原真實 leader，提供多角度清晰照訓練一致性參考，並在 M2 比對簽核。

## 5. 路線選擇建議

| 你的情況 | 建議 |
|----------|------|
| 活動在 3 個月後、想要傳世品質 | 路線 B（獨立 CG） |
| 活動在 6–8 週內、預算有限 | 路線 C（AI 輔助） |
| 想先看效果再決定 | 先用路線 C 做 **90 秒精華版** 試水溫，反應好再升級 B |
| 預算充足、要每年複用的旗艦資產 | 路線 A（工作室級），角色資產可重複用於未來影片 |
