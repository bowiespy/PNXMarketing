# 08｜CG 細緻度全參照 (CG Detail Reference)

> 用戶要求：「細節到 120fps、做 CG 的那種細緻程度等級，CG 要有哪些細節我通通都要完全參照」。
> 本文件列出一支「Pixar/Soul 級」CG 鏡頭從動作到像素需要照顧的**所有細緻度維度**，
> 作為 `09_PROMPT_BIBLE.md` 每個 prompt 的品質標尺 (quality bar) 與檢查清單。

---

## 0. 一句話原則

> **「不要一個畫面一個動作」＝ 每個瞬間都要有「主動作 + 次動作 + 微動作 + 環境反應」四層同時發生。**
> 真實感來自「層層疊疊、永不靜止」的細節——靜止的只有死物，連死物也有空氣與光在動。

---

## 1. 時間與動態 (Time & Motion) — 對應「120fps 那種」

| 細節 | 說明 | 製作要點 |
|------|------|----------|
| 影格率 Frame Rate | 成片建議 **24fps（電影感）** 為主；高速/慢動作鏡頭**以 60–120fps 算圖**再做變速 | 動畫師可用 120fps 思維設計「子幀運動」，輸出再 retime |
| 動態模糊 Motion Blur | 真實鏡頭的快門殘影；**必開**，依快門角度 180° | 算圖開 motion blur，或合成 vector blur |
| 子幀運動 Sub-frame | 高速物體（光鳥振翅、鼓點卡點）在單格內的位移軌跡 | 高 fps 算再降，避免頻閃 (strobing) |
| 慢動作 Slow-mo | ⑥橋段情緒拍 | 用高 fps 來源做 optical-flow 補幀 retime |
| 動畫 12 原則 | 擠壓拉伸/預備/跟隨/重疊/緩入緩出/弧線/次要動作/節奏/誇張/實感/吸引力 | 角色動畫驗收硬指標 |
| 緩動曲線 Easing | 沒有等速運動；一切有加減速 | f-curve 不留直線段 |
| 重量與意圖 Weight & Intent | 動作有質量、有目的 | 重心轉移、預備動作不可省 |

---

## 2. 角色動畫細節 (Character Animation)

- **主動作 (primary)**：角色的主要意圖動作（走、遞、抬頭）。
- **次動作 (secondary)**：手指捲動、衣角、頭髮、配件的被動跟隨。
- **微動作 (micro)**：呼吸起伏、重心微晃、眨眼、視線游移、吞嚥。
- **重疊與跟隨 (overlap & follow-through)**：身體停了，頭髮/衣服/筆記還在動。
- **預期 (anticipation)**：出手前先後拉。
- **保持鮮活 (moving hold)**：「靜止」鏡頭仍有呼吸與微飄，杜絕死格 (dead frame)。
- **接觸與互動 (contact)**：手搭肩有壓陷、遞物有交接重量、踩地有反作用。
- **群戲節奏 (staggered timing)**：群眾不齊動，錯開 2–5 幀避免「複製人」。

---

## 3. 臉部與表演 (Face & Performance)

| 細節 | 要點 |
|------|------|
| FACS 表情系統 | 以面部動作單元 (Action Units) 驅動，≥40 blendshape |
| 微表情 Micro-expression | 眉內側上揚、眼輪匝肌收縮（杜鄉微笑）、嘴角不對稱、鼻翼 |
| 眼睛 Eyes | 角膜濕潤反光、虹膜紋理與景深、瞳孔隨光收放、catchlight 眼神光、紅血絲 |
| 眨眼 Blink | 不規則節奏、情緒影響頻率、半眨、思考時眼球掃視 (saccade) |
| 視線 Eye-line | 對戲時精準對視 / 思考時失焦遠望 |
| 對嘴 Lip-sync | viseme（音素口型）對齊歌詞，下巴/舌/唇連動 |
| 皮膚動態 | 笑出魚尾紋、額頭抬紋、皮膚滑動 (skin sliding) |
| 淚 Tears | 眼眶含光、滑落軌跡、鼻頭泛紅 |

---

## 4. 模擬 (Simulation) — 讓一切「活」起來

| 系統 | 用途 |
|------|------|
| 頭髮 Hair/Fur | 逐根動態、風與慣性、汗濕貼額、飛起髮絲 |
| 布料 Cloth | 西裝/襯衫的重力垂墜、皺褶、被風吹、坐下擠壓、奔跑飄動 |
| 肌肉/脂肪 Muscle/Jiggle | 次表面軟組織隨動作晃動，避免僵硬塑膠感 |
| 軟體 Soft-body | 咖啡晃、紙張翻、椅墊陷 |
| 流體 Fluids | 雨、咖啡、潑濺、海/河面 |
| 剛體 Rigid | 散落紙張、掉落物、碎裂 |

---

## 5. 材質與著色 (Surfacing / Shading)

- **PBR 物理材質**：albedo / roughness / metallic / normal / displacement / AO 完整貼圖。
- **皮膚次表面散射 (SSS)**：耳朵/鼻翼透光、紅潤血色、毛孔級 micro-detail（這是 Pixar 溫暖感關鍵）。
- **微位移 Micro-displacement**：毛孔、布紋、紙纖維、磨砂金屬。
- **多層材質**：清漆車漆 (clearcoat)、眼睛多層（角膜+虹膜+鞏膜）、汗膜/油光。
- **磨損與故事感**：筆記本翻舊的卷邊、咖啡杯漬、白板殘字、舊辦公室刮痕——道具要有「被用過」的痕跡。
- **發光材質 Emission**：阿凱藍火、阿俊暖光、燈海——emission + bloom 友善，避免死白。

---

## 6. 燈光 (Lighting)

| 細節 | 要點 |
|------|------|
| 全局照明 GI | 光的多次反彈、色溢 (color bleed)，藍金互染 |
| 三點打光 + 動機光 | key/fill/rim，但每盞燈有「劇情來源」（窗、桌燈、火種） |
| 體積光 Volumetrics | god rays、霧、塵埃浮游、光束實體感 |
| 環境光遮蔽 AO | 接縫/角落的細微陰影 |
| 焦散 Caustics | 玻璃帷幕、水面、咖啡杯的折射光斑 |
| 接觸陰影 Contact Shadow | 物體落地處的硬陰影 |
| 區域光柔影 | 軟陰影邊緣 (penumbra)，非硬切 |
| 色溫對比 | 陰影偏冷藍、高光偏暖金（PropNex 日落感） |

## 7. 攝影與鏡頭 (Camera & Lens) — 擬真實體攝影機

- **景深 DoF**：焦平面、散景 (bokeh) 形狀（光圈葉片）、前/後景虛化。
- **鏡頭運動**：手持微晃、推軌、升降、環繞 oner，皆有加減速與輕微 overshoot。
- **真實鏡頭瑕疵（適量）**：色散 (chromatic aberration)、暗角 (vignette)、鏡頭眩光 (lens flare)、光斑 (bokeh highlights)、呼吸效應 (focus breathing)。
- **快門與曝光**：高光溢出 bloom、過曝邊緣、自動曝光的微調感。
- **焦段語言**：長焦壓縮情緒、廣角誇張規模（見 `03` 第3節）。
- **構圖**：三分法、引導線、前景遮擋 (foreground occlusion) 增加層次與縱深。

---

## 8. 特效 (FX)

雨絲與濺落、地面濕反光、霧與體積雲、塵埃浮游、光粒子（火種/燈海/光字）、
光鳥的能量拖尾、神光、能量交融、空拍雲層、煙霧、漂浮文字光雕。
原則：FX 要與角色動畫**互動**（雨打在肩上會散、光經過會照亮臉），不可各演各的。

---

## 9. 群眾 (Crowd)

- agent instancing + 隨機變化（身高/膚色/服裝/動作 offset）避免複製感。
- 動作循環庫 (cycle library) + 個別 hero 角色穿插。
- LOD 分層：近景精細、中景簡化、遠景 impostor/粒子（2000 人燈海用此法）。

---

## 10. 算圖與分層 (Render / AOV) 與後期

- **AOV 多層輸出**：beauty / diffuse / specular / SSS / emission / volume / depth (Z) / normal / motion-vector / cryptomatte / AO / shadow。
- **降噪 Denoise**：採樣足夠 + AI 降噪，避免螢火蟲 (fireflies)。
- **合成 Compositing**：分層調控、加 DoF（用 Z 深度）、bloom、glow、grain、暗角、色差。
- **顆粒 Film Grain**：細微底片顆粒統一質感，去除「太乾淨的數位感」。
- **調色 Grade**：統一 LUT，陰影冷/高光暖，膚色保護。
- **連戲 Continuity**：光源方向、角色服裝/道具、藍火/暖光強度跨鏡一致。

---

## 11. 鏡頭級「四層細節」自檢表

> `09` 每個 prompt 出來後，用這張表檢查它是否「夠 CG、不像投影片」：

- [ ] **主動作**：角色主要意圖清楚？
- [ ] **次動作**：衣/髮/配件有跟隨？
- [ ] **微動作**：呼吸/眨眼/重心微晃/視線有戲？
- [ ] **環境反應**：光/塵/雨/布/液體對動作有回應？
- [ ] **鏡頭**：有運動、有景深、有動態模糊？
- [ ] **多角度覆蓋**：這個 beat 是否有 establishing+medium+CU+insert+reaction 多顆鏡頭？
- [ ] **連戲**：光向、道具、藍火/暖光強度與前後鏡一致？
- [ ] **情緒卡點**：對上音樂節拍/歌詞關鍵字？
