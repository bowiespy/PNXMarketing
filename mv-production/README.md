## 核心設計亮點

- **雙主角**：阿凱（藍火・精進/帶團隊/跟老闆培訓）× 阿俊（暖光・好大哥/關懷 agent）。
- **四位老闆全片穿插**：Marcus / Evon / Steve / Yuki 在火種、培訓台、project 現場、頒獎、燈海群像反覆出現。
- **歌詞驅動**：8 環節逐句對位真實歌詞，hook（sharpen the wing / Think Big / thousands to millions）有專屬視覺記憶點。
- **音樂精準對位**：實測雙副歌結構，兩個能量高峰 (0:44 / 1:57) 對上兩個「光」爆發。
- **PropNex 品牌色 × 暖光辯證**：藍（事業/精進）× 琥珀（家庭/關懷）→ 最終藍金燈海 = 事業成功×家庭幸福。
- **CG 細緻度到位**：八維度 prompt + 四層運動 + 多角度覆蓋，確保「像電影、不像投影片」。

## 八維度 Prompt 系統（`09`）
每顆鏡頭都填滿：**美術 / 編導 / 場景 / 鏡頭 / 動作 / 表情 / 情緒 / 調色** + 全域 CG 品質尾綴。
每個故事 beat 拆成多角度覆蓋（establishing→medium→CU→insert→reaction），杜絕一畫面一動作。

## 待補素材
1. 兩位 leader 的真名/形象（替換佔位「阿凱/阿俊」）—— 或確認維持虛構代言角色
2. 四位老闆官方**多角度照片** + 肖像使用授權（對外片必需）
3. PropNex **Logo 向量檔 / 品牌標準字**
4. 確認成長數據（67→2000、全馬據點）與目標**活動日期**（回推排程）
5. 歌曲逐字 timecode（animatic 階段用波形鎖定）
