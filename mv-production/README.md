## 一句話故事
八年前當所有人說「不可能」，兩個一無所有的年輕人選擇相信四位創辦人手中那束光；
八年後，他們把 67 人的小團隊，變成遍佈全馬、2000 人的家。**這是一群人決定「相信」的故事。**

## 核心設計亮點

- **雙主線**：阿浩（建系統）× 凱琳（立文化）＝公司成長的兩條腿，第④段交會、第⑦段合流。
- **母題符號**：一束光 / 一盞燈——從創辦人的火種，到 2000 盞燈連成燈海，最後升空成「市場北極星」。
- **音樂精準對位**：實測歌曲為雙副歌結構，兩個能量高峰 (0:44 / 1:57) 正好對上兩個「光」的視覺爆發。
- **冷→暖色彩弧線**：用顏色說情緒，從質疑的灰藍走到信念燎原的暖金。
- **可拆可合**：8 段各自能當社群短片，剪在一起又是完整一齣劇。
