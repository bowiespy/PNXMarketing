# 00｜製作標準 + 全片鏡頭母表 (Production Standard & Master Shot List)

## 1. 技術標準 (Tech Spec — 全片鎖定)

| 項目 | 規格 |
|------|------|
| 影格率 Frame Rate | **24fps** 交付（電影感）。hero/慢動作鏡頭以 **48–120fps** 算圖再 retime |
| 解析度 | **3840×2160 (4K UHD)**，工作檔 16:9 |
| 安全框 | Action-safe 93% / Title-safe 90% |
| 色彩空間 | 線性工作流 ACEScg，輸出 Rec.709 / sRGB；母帶 ProRes 4444 |
| 鏡頭基準 | 全片用「擬真實體攝影機」：35mm 全幅等效，景深/快門/暗角/色散物理正確 |
| 快門 | 180° shutter（動態模糊基準） |
| 預設手持 | hero 鏡微幅手持噪波（位移 ≤ 2px@4K、旋轉 ≤ 0.15°），紀錄片質感 |
| 收尾黑 | 片尾 logo 後 12 幀淡黑 |

**時間碼標記法**：本腳本用 `f<起>–<迄>`（絕對幀，24fps）＋秒數。例：`f0–96 (0.0–4.0s)`。
換算：`秒 = 幀 / 24`。

## 2. 怎麼讀一顆鏡頭 (Shot Block 格式)

SEQ 檔裡每顆鏡頭都含下列欄位，**缺一不可**：

```
SHOT 1.01 — 標題
■ TC        f0–96 ｜ 0.0–4.0s ｜ Dur 96f / 4.0s
■ SEQ/SCENE SEQ01 火種 ｜ INT/EXT・地點・時間
■ SIZE/LENS 景別 ｜ 焦段(mm) ｜ 光圈 ｜ 對焦點
■ CAMERA    機位角度 + 運動（含幀區間的運動曲線 ease）
■ STAGING   走位/構圖/前中後景分層（含三分法落點）
■ ACTION    逐幀區間的動作（f0–12: … / f12–40: …），標主/次/微/環境四層
■ KEYS      hero 鏡的關鍵姿勢表（幀 → pose）；非 hero 可略
■ FACE      表情/眼神/視線/對嘴 viseme（有角色時）
■ FX        粒子/流體/體積/模擬 cache
■ LIGHT     key/fill/rim + practical 光，色溫與強度比
■ COLOR     主色盤 HEX + 冷暖比 + 對應 03 color script
■ AUDIO     音樂卡點幀 + 歌詞句 + 音效 SFX
■ EDIT      與前後鏡的剪接方式（cut on action / match cut / dissolve…）
■ ASSETS    需要的 model / rig / sim / set / prop
■ RENDER    需輸出的 AOV 與特殊 pass
■ NOTE      給動畫師的提醒、替代方案
```

## 6. 跨鏡連戲檢查 (Continuity Locks)

- 阿凱藍火、阿俊暖光的**強度隨劇情單調遞增**（SEQ01 最弱 → SEQ07/08 最強），跨鏡不可忽明忽暗。
- 光源方向跨鏡一致；轉場用「動接動 / 光接光」。
- 四老闆每次出場，主角靈魂光必亮一下（因果連戲）。
- 兩個 ★ 卡點（f1056、f2808）必須與音樂落點對齊，誤差 ≤ 2 幀。
